## SPW Lyrics Island v1.10.1-BASS-GPU

本正式版基于已通过实际使用测试的 `1.10.1-test.2` 构建。

### 歌词检索与缓存

- 歌词请求失败或取消时跳过无歌词缓存写入。成功返回的空结果仍会缓存。取消时关闭连接，并恢复仍在等候的共享请求。
- 本地 LRC、内嵌歌词或相似度设置发生变化时，重新检查自动歌词缓存，并保留手动选择记录和缓存过期机制。
- Apple Music 歌词可按 ISRC 从 `lrc.red` 查询 TTML，保留旧 Apple ID 选择的回退方式和歌词来源署名。

### 渲染与界面交互

- 切歌或字号变化时重置预留歌词高度。在空闲时回收过大的画布，手势操作和动画期间保持画布稳定。
- 改进 Windows 截图工具录屏栏避让，以及玻璃弹窗的指针和滚轮事件路由恢复。
- 当前字体缺字时，尝试使用系统已安装字体回退。
