# 兼容性与限制

[← 文档首页](README.md)

## 平台

需要支持 Workshop API dev23 的 SPW 1.19.0 或更高版本，以及 Java 25 或更高版本的宿主运行环境。

Windows x64 和 Linux x64 共用一个 `.spmod`，运行时自动选择平台组件。Windows 是主要开发环境并提供完整功能，Linux 为实验性支持。

| 平台 | 状态 | 说明 |
| --- | --- | --- |
| Windows 10 / 11 x64 | 支持 | 本 fork 唯一支持并构建的平台；音频环境要求见下文 |
| Linux x64 | 本 fork 不再提供 | 上游曾有实验性支持，本 fork 已移除 |
| macOS | 暂无计划 | 当前没有构建和平台适配 |
| Android / iOS / HarmonyOS | 不支持 | Salt Player 当前没有对应插件运行环境 |

## 液态玻璃

仅支持 Windows 11 SDR 桌面，需要可用的 Direct3D GPU 绘制。词岛、右键菜单和关于页共用该背景样式。Windows 10、HDR 和 Linux 使用经典背景。

启用时，使用液态玻璃的词岛、菜单、关于页及对应输入窗口会从支持系统捕获排除的录屏中消失。关闭液态玻璃后恢复；插件不保存桌面图像。

低性能模式、捕获或 Shader 不可用时使用经典背景。词岛轮廓跨出单屏采样范围时暂用经典背景；菜单和关于页在切屏等待新图像时保留上一帧材质。“关于与状态”的“渲染与材质”分组显示当前传输方式、背景更新率和回退原因。

## 歌词和 SPW

托盘图标和实时频谱需要本机的 .NET Framework 4.x，频谱的其他运行条件见下文。字体选择器使用插件内置的 Compose 界面。

词岛只显示 SPW 已经加载的歌词，不会自己联网搜索、上传歌词，也不会修改歌曲或歌词文件。需要自动获取逐字歌词时，可以搭配 [SPW-Lyrics](https://github.com/GaBoron/SPW-Lyrics)。

单行和实验性多行模式均使用宿主公开的完整歌词时间轴与当前行回调。换曲或重新加载歌词时，宿主发布的空列表会清除上一份歌词。

同时启用多个会参与歌词加载的插件时，SPW 的回调顺序也可能影响最终结果。如果问题只出现在某个插件组合下，反馈时最好把组合一起写上。

### 非 1× 播放速度

词岛根据 SPW 回传的播放位置估计倍速，用于两次位置回调之间的逐字高亮和进度显示。刚切换倍速时需要收到后续位置回调才能更新估计；如果宿主停止回传位置，时间轴会在短时间后冻结。

## 本地歌曲、封面和总时长

获得曲库读取权限时，优先使用 SPW 公开 API 提供的歌曲总时长和内嵌封面；缺失或未授权时从当前本地音频文件补充。

封面按下面的顺序尝试：

1. SPW 公开 API 返回的内嵌封面；
2. 本地音频文件内嵌封面；
3. 同目录 `cover.jpg`、`cover.png`、`folder.jpg`、`folder.png`。

网络歌曲、不可访问文件或没有封面的歌曲会使用占位图。

展开后的进度条需要可靠的歌曲总时长。本地音频通常没问题；网络歌曲、无法访问的文件或不能可靠解析时长的格式，可能只能显示当前播放时间，不能提供完整 seek 进度条。歌词和上一首 / 播放暂停 / 下一首仍可正常用。

## 实时频谱与音频输出

实时频谱只捕获 SPW 进程及其子进程的音频，不会读取麦克风、其他应用或完整系统混音，也不会保存录音。

运行条件：

- Windows build 20348 或更高；
- 可用的 .NET Framework 4.x；
- 共享模式音频输出。

独占模式、ASIO 或其他绕过共享音频链路的输出方式可能无法捕获。实时捕获失败时，词岛会退回轻量模拟频谱，不影响歌词显示。

低性能模式会主动停用实时音频捕获，所以这时看到模拟频谱是正常的。

## 快捷键和窗口行为

授予快捷键权限后，默认 `Ctrl+Shift+D` 在 SPW 内显示 / 隐藏词岛。可以在 SPW 快捷键管理中修改键位或配置全局快捷键；冲突和输入框内的应用内快捷键由 SPW 处理。撤销权限后快捷键停用，托盘和插件设置仍可使用。

“全屏时隐藏”依赖前台窗口判断。动态壁纸、桌面增强软件或其他铺满屏幕的窗口偶尔也会被识别为全屏。

字体缺字时先使用当前歌词字体；默认内置苹方缺少字形时回退到内置 MiSans，再回退到系统字体；系统仍无对应字形时才会显示缺字框。

如果上表中标记为支持的功能实际没有正常工作，请看 [故障排查](troubleshooting.md)。更底层的实现和平台架构放在 [开发指南](development.md)。
